**60 tools for Czech and global medical sources**

Open-source MCP server for Claude, Cursor or VS Code. 23 Czech tools (SÚKL, MKN-10, NRPZS, SZV, VZP) and 37 global biomedical ones (PubMed, Europe PMC, bioRxiv and more).

`Python` `MCP` `uv` `Railway`

[Docs →](https://czech-med-mcp-docs.vercel.app)

</td>

### 📚 [OpenClinical Knowledge Base CZ](https://github.com/petrsovadina/OpenClinical-Knowledge-Base-CZ)
**Czech medical texts as machine-readable data**

Turns unstructured guidelines, SPCs and regulatory bulletins into structured JSON for RAG, chatbots and decision support. For research and education — not a medical device under MDR.

`TypeScript` `JSON` `RAG`

</td>

**Assisted ICD-11 (MKN-11) diagnosis coding**

GPT-4 extracts diagnoses from unstructured text, suggests MKN-11 codes and gives each suggestion a confidence score.

`TypeScript` `Next.js` `OpenAI`
